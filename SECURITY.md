# Security Policy

## Supported Versions

| Version              | Supported |
| -------------------- | --------- |
| Latest (main branch) | Yes       |
| Older releases       | No        |

## Reporting a Vulnerability

Please report security vulnerabilities privately and include a description, reproduction steps, potential impact, and a suggested fix when available. Do not open a public issue for a security vulnerability.

**Email:** [nexzadevbusiness@proton.me](mailto:nexzadevbusiness@proton.me)
